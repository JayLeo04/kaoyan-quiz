# 第 6 章 树和二叉树

> **📌 本章主线**
>
> 树用递归的层次关系组织结点；二叉树进一步固定“左、右”两个有序位置，使性质推导、存储、遍历和计数都可精确表达。遍历把非线性结构线性化，线索化复用空链域保存遍历前驱与后继；孩子—兄弟表示又把一般树、森林和二叉树统一到同一套二叉链表解释中。集合的查找与合并、哈夫曼编码、回溯状态树和 Catalan 计数分别展示了树在集合划分、最优编码、搜索和组合计数中的应用。

>

## 6.1 树的定义和基本术语

<!-- source: section="6.1" source_file="6-1-tree-definition-basic-terms/index.md"

### 递归定义与逻辑表示

树是 $n$ 个结点的有限集，$n\ge 0$。$n=0$ 时为空树；任意非空树满足：

1. 有且仅有一个根结点；
2. 当 $n>1$ 时，除根外的结点可划分为 $m$ 个互不相交的非空有限集 $T_1,T_2,\ldots,T_m$，$m>0$；
3. 每个 $T_i$ 本身仍是一棵树，称为根的一棵子树。

递归定义同时限定了“唯一根”“子树互不相交”和“子树仍满足同一定义”。例如，以 A 为根时可有

$$
T_1=\{B,E,F,K,L\},\quad
T_2=\{C,G\},\quad
T_3=\{D,H,I,J,M\},
$$

三个集合两两不相交，并分别构成 A 的子树。

逻辑上，一棵非空树可写成

$$
Tree=(root,F),\qquad F=\{T_1,T_2,\ldots,T_m\}.
$$

当 $m>0$ 时，根与各子树根 $r_i$ 的关系为

$$
R_F=\{\langle root,r_i\rangle\mid i=1,2,\ldots,m\}.
$$

森林是 $m$ 棵互不相交的树的集合，$m\ge 0$；一个结点的全部子树也构成森林，因此树与森林可以相互递归地描述。

### 基本术语

| 术语 | 定义与边界 |
| --- | --- |
| 结点的度 | 该结点拥有的子树数 |
| 叶子/终端结点 | 度为 0 的结点 |
| 分支结点/非终端结点 | 度不为 0 的结点；除根外也称内部结点 |
| 树的度 | 树内各结点度的最大值 |
| 孩子与双亲 | 某结点子树的根是其孩子，该结点是孩子的双亲 |
| 兄弟 | 具有同一双亲的孩子 |
| 祖先与子孙 | 从根到该结点路径上、除该结点自身外的结点是其祖先；以某结点为根的子树中其他结点是其子孙 |
| 层次 | 根为第 1 层；第 $i$ 层结点的孩子在第 $i+1$ 层 |
| 堂兄弟 | 双亲位于同一层的结点 |
| 深度/高度 | 树中结点的最大层次 |
| 有序树/无序树 | 各子树从左到右不可互换时为有序树，否则为无序树 |

树还可用嵌套集合、广义表或凹入表表示；三种写法改变的是外观，不改变根、子树划分和层次关系。

### ADT Tree 的操作边界

`Tree` 的数据对象 $D$ 是具有相同特性的数据元素集合；数据关系由唯一根和递归子树划分给出。常用操作压缩如下：

| 操作组 | 接口与结果 |
| --- | --- |
| 建立与清理 | `InitTree` 构造空树；`CreateTree` 按定义建立；`DestroyTree` 销毁；`ClearTree` 清为空树 |
| 状态与属性 | `TreeEmpty`、`TreeDepth`、`Root`、`Value`、`Assign` |
| 亲属关系 | `Parent`、`LeftChild`、`RightSibling`；不存在相应结点时返回“空” |
| 修改 | `InsertChild(&T,&p,i,c)` 将 `c` 插为 `p` 的第 $i$ 棵子树；`DeleteChild(&T,&p,i)` 删除第 $i$ 棵子树 |
| 遍历 | `TraverseTree(T,Visit)` 按指定次序对每个结点调用访问函数 |

除初始化和按定义建立外，上述操作均以树已经存在为前提。插入还要求 $p$ 指向树内结点、$1\le i\le degree(p)+1$、非空树 $c$ 与原树不相交；删除要求 $1\le i\le degree(p)$。遍历中任一次 `Visit` 失败，整个操作即失败。

## 6.2 二叉树

<!-- source: section="6.2" source_file="6-2-binary-tree/index.md"

### 二叉树的定义与操作

二叉树或为空，或由一个根结点以及两棵互不相交、分别称为左子树和右子树的二叉树组成。每个结点至多有两个孩子，且左右位置有序，不能任意交换。

> **⚠ 易错提醒**
>
> 二叉树不只是“度不超过 2 的普通树”。即使某结点只有一个孩子，也必须区分它是左孩子还是右孩子；空的左、右位置同样参与结构判定。

二叉树有 5 种基本形态：空树、只有根、只有左子树、左右子树均非空、只有右子树。树的层次、度、叶子、祖先等术语均可用于二叉树。

`BinaryTree` 的建立、清理、取值和遍历操作与 `Tree` 同类，但关系操作明确区分 `LeftChild`、`RightChild`、`LeftSibling` 和 `RightSibling`。教材的 `InsertChild(T,p,LR,c)` 还规定：`LR` 为 0 或 1；非空二叉树 `c` 与 `T` 不相交且 `c` 的右子树为空；插入后，`p` 原有的对应子树成为 `c` 的右子树。`DeleteChild` 删除 `p` 的左或右子树。四种遍历接口分别为先序、中序、后序和层序遍历，并要求每个结点恰好访问一次。

### 五条基本性质

设根位于第 1 层。

1. **层结点上界**：第 $i$ 层至多有 $2^{i-1}$ 个结点，$i\ge 1$。归纳步使用“每个结点至多产生两个孩子”。
2. **总结点上界**：深度为 $k$ 的二叉树至多有

   $$
   \sum_{i=1}^{k}2^{i-1}=2^k-1,\qquad k\ge 1.
   $$

3. **叶子与二分支结点关系**：任意非空二叉树中，若度为 0、1、2 的结点数分别为 $n_0,n_1,n_2$，则

   $$
   n=n_0+n_1+n_2. \tag{6-1}
   $$

   除根外每个结点恰有一条进入分支，故分支数 $B=n-1$；另一方面 $B=n_1+2n_2$，于是

   $$
   n=n_1+2n_2+1. \tag{6-2}
   $$

   联立得

   $$
   n_0=n_2+1.
   $$

4. **完全二叉树的深度**：具有 $n$ 个结点的完全二叉树深度为（$n\ge 1$）

   $$
   \lfloor\log_2 n\rfloor+1.
   $$

   若深度为 $k$，完全二叉树满足 $2^{k-1}\le n<2^k$，故 $k-1\le\log_2n<k$。
5. **完全二叉树的编号关系**：按层序从 1 开始、自上而下且每层从左到右编号。对 $1\le i\le n$：

   $$
   \operatorname{PARENT}(i)=\left\lfloor\frac i2\right\rfloor\quad(i>1),
   $$

   $$
   \operatorname{LCHILD}(i)=2i\quad(2i\le n),
   $$

   $$
   \operatorname{RCHILD}(i)=2i+1\quad(2i+1\le n).
   $$

   $i=1$ 时无双亲；$2i>n$ 时无左孩子且该结点为叶子；$2i+1>n$ 时无右孩子。

### 满二叉树与完全二叉树

深度为 $k$ 且有 $2^k-1$ 个结点的二叉树是满二叉树。将满二叉树按层序连续编号后，深度为 $k$、含 $n$ 个结点的二叉树若与编号 $1$ 至 $n$ 的结点逐一对应，就是完全二叉树。

完全二叉树的叶子只可能位于最大层和次大层。对任一结点，若右子树的最大层次为 $l$，则左子树的最大层次只能为 $l$ 或 $l+1$。

### 顺序存储与链式存储

顺序存储用连续数组按层序保存完全二叉树。教材数组下标从 0 开始，逻辑编号为 $i$ 的结点存于下标 $i-1$：

```c
#define MAX_TREE_SIZE 100
typedef TElemType SqBiTree[MAX_TREE_SIZE];
```

一般二叉树若套用这种编号，缺失结点的位置仍须保留空单元。最坏情况下，深度为 $k$、仅有 $k$ 个结点的单支树需要长度为 $2^k-1$ 的数组，因此顺序存储实际适合完全二叉树。

二叉链表至少包含数据、左孩子指针和右孩子指针：

```c
typedef struct BiTNode {
    TElemType data;
    struct BiTNode *lchild, *rchild;
} BiTNode, *BiTree;
```

含 $n$ 个结点的二叉链表共有 $2n$ 个孩子指针域，其中 $n-1$ 个保存分支，故有 $n+1$ 个空链域。增加双亲指针后成为三叉链表：查双亲可直接沿双亲域完成；二叉链表则需从根开始搜索。存储结构的选择不仅取决于树形，还取决于需要频繁执行的操作。

     pdf_pages="138-145" book_pages="128-135" items="算法6.1-6.7, 式(6-3)-式(6-5), 图6.9-图6.12" -->

### 遍历次序与递归定义

遍历是沿某条搜索路径访问每个结点一次且仅一次。以 $D$ 表示访问根、$L$ 表示遍历左子树、$R$ 表示遍历右子树，三部分共有 6 种排列；限定先左后右后，得到：

| 次序 | 递归步骤 | 根的访问时机 |
| --- | --- | --- |
| 先序 DLR | 根 → 左 → 右 | 两棵子树之前 |
| 中序 LDR | 左 → 根 → 右 | 左子树之后、右子树之前 |
| 后序 LRD | 左 → 右 → 根 | 两棵子树之后 |

空树的三种遍历均为空操作。算法 6.1 的先序递归实现必须逐层传播 `Visit` 或子调用失败：

```c
Status PreOrderTraverse(BiTree T, Status (*Visit)(TElemType)) {
    if (!T) return OK;
    if (!Visit(T->data)) return ERROR;
    if (!PreOrderTraverse(T->lchild, Visit)) return ERROR;
    return PreOrderTraverse(T->rchild, Visit);
}
/* 算法 6.1 的核心 */
```

三种递归算法的调用轨迹相同，差别只在 `Visit` 位于两次递归调用的前、中还是后。


### 表达式树与遍历序列

若叶子保存操作数、内部结点保存运算符，表达式 $a+b*(c-d)-e/f$ 的三种序列为；按教材约定，一元运算符结点的左子树为空。

$$
-+a*b-cd/ef, \tag{6-3}
$$

$$
a+b*c-d-e/f, \tag{6-4}
$$

$$
abcd-*+ef/-. \tag{6-5}
$$

它们分别对应前缀、中缀和后缀表示。中缀字符序列本身不展示表达式树中隐含的括号层次；树结构仍由左右子树关系保存。

### 中序非递归遍历

算法 6.2 把根指针入栈，并继续把左孩子指针（包括空指针）压栈；弹出空指针表示左路到头，再弹出待访问根并把右孩子压栈。算法 6.3 不保存空指针，以游标 `p` 与栈共同表示搜索状态：

```c
Status InOrderTraverse(BiTree T, Status (*Visit)(TElemType)) {
    InitStack(S);
    BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            Push(S, p);
            p = p->lchild;
        } else {
            Pop(S, p);
            if (!Visit(p->data)) return ERROR;
            p = p->rchild;
        }
    }
    return OK;
}
/* 算法 6.3 的核心 */
```

循环中，`p` 指向尚未处理的当前子树；栈中保存“左子树正在处理或已经处理、根尚待访问”的祖先。弹栈访问根后转向右子树，直到 `p` 为空且栈空才终止。

### 先序序列建树

算法 6.4 用带空树标记的先序序列唯一恢复二叉链表。读到空格字符就置空指针；否则建立根，再递归建立左、右子树：

```text
CreateBiTree(T as output)
    ch ← ReadOneCharacter()
    if ch is the blank marker
        T ← NULL
    else
        allocate root T; T.data ← ch
        CreateBiTree(T.lchild)
        CreateBiTree(T.rchild)
/* 算法 6.4 的核心；教材以空格字符表示空树 */
```

仅有非空结点的先序序列不足以一般性地确定树形；空子树标记承担结构边界。

> **🧭 教材写法与应试实现**
>
> 原书 PDF 第 141 页（书页 131）的算法 6.4 确实印为 `scanf(&ch);`，并以 `ch==' '` 判空；前者缺少格式串，不是可直接照抄的标准 C 调用。若在 C 答题中仍用 `scanf`，应写成 `if (scanf("%c", &ch) != 1) return ERROR;`。格式串不能写成 `" %c"`，因为前导空白会跳过本算法用作空树标记的空格；无论采用何种字符输入接口，都必须保持“每次恰读一个字符、空格表示空树”的序列化约定。

三种遍历对 $n$ 个结点各访问一次，时间复杂度均为 $O(n)$。递归栈或显式栈的最大容量由树高 $h$ 决定，辅助空间为 $O(h)$，单支树最坏为 $O(n)$。

若存储结构另带双亲和遍历状态标志，也可沿这些字段回退而不另设栈；教材同时指出，这种替代会付出额外时间代价，并非普通二叉链表上的免费优化。

### 线索、标志域与中序前驱/后继

遍历把二叉树线性化，使除序列首、尾外的结点各有一个直接前驱和后继。二叉链表的 $n+1$ 个空链域可复用为线索：

| 标志 | 含义 |
| --- | --- |
| `LTag=0` | `lchild` 指向左孩子 |
| `LTag=1` | `lchild` 指向遍历前驱 |
| `RTag=0` | `rchild` 指向右孩子 |
| `RTag=1` | `rchild` 指向遍历后继 |

由此形成线索链表；加上线索的树称为线索二叉树，把空指针改成相应前驱/后继的过程称为线索化。这里的“前驱、后继”始终相对于某一种已指定遍历次序。

在中序线索树中：

- 若 `RTag=1`，右链直接指向后继；若 `RTag=0`，后继是右子树中沿真实左孩子走到的最左结点。
- 若 `LTag=1`，左链直接指向前驱；若 `LTag=0`，前驱是左子树中沿真实右孩子走到的最右结点。

后序后继还依赖双亲关系：

1. $x$ 为根时，后继为空；
2. $x$ 是双亲的右孩子，或是双亲的左孩子且双亲无右子树时，后继是双亲；
3. $x$ 是双亲的左孩子且双亲有右子树时，后继是双亲右子树按后序访问的第一个结点。

因此，仅靠二叉线索链表不能方便地求后序后继，教材要求采用带标志域和双亲指针的三叉链表。

### 带头结点的中序线索链表

设头结点为 `T`：

- 头结点的 `LTag=Link`、`RTag=Thread`；
- `T->lchild` 指向根；空树时回指 `T`；
- `T->rchild` 指向中序最后一个结点；空树时回指 `T`；
- 中序第一个结点的前驱线索和最后一个结点的后继线索均指向 `T`。

这样形成双向线索链表，可从首结点顺后继遍历，也可从尾结点逆前驱遍历。算法 6.5 的顺向遍历过程是：先沿真实左孩子到序列首结点；访问后沿连续后继线索前进；遇到真实右孩子时转入右子树并再次寻找最左结点。遍历仍为 $O(n)$，但不另设栈。

### 中序线索化不变量

算法 6.6 建立头结点并处理首尾边界；算法 6.7 在中序遍历过程中修改空链。访问当前结点 `p` 之前，`pre` 始终指向刚刚访问的结点，也就是 `p` 的中序前驱；访问序列首结点前，`pre` 初始化为头结点哨兵：

```c
void InThreading(BiThrTree p) {
    if (!p) return;
    InThreading(p->lchild);
    if (!p->lchild) {
        p->LTag = Thread;
        p->lchild = pre;
    }
    if (!pre->rchild) {
        pre->RTag = Thread;
        pre->rchild = p;
    }
    pre = p;
    InThreading(p->rchild);
}
/* 算法 6.7 的核心 */
```

非空树线索化结束后，还要把最后一个结点的后继设为头结点，并令头结点的右链指向该结点。线索指针只能在对应孩子指针原本为空时写入，不能覆盖真实子树。

### 三类存储表示

| 表示法 | 关键字段 | 擅长的操作 | 代价与边界 |
| --- | --- | --- | --- |
| 双亲表示 | 连续数组中的 `data,parent`；根的 `parent=-1` | 由结点找双亲；沿双亲链找根 | 找某结点全部孩子需扫描数组 |
| 孩子表示 | 顺序结点保存孩子链表头；链结点保存孩子下标和 `next` | 枚举孩子 | 单独使用时不便找双亲；可增设双亲域组合使用 |
| 孩子—兄弟表示 | `firstchild` 指向第一个孩子，`nextsibling` 指向下一个兄弟 | 统一表示任意度数，并可转成二叉链表 | 找第 $i$ 个孩子需先到第一个孩子，再沿兄弟链走 $i-1$ 步；找双亲仍需额外字段或搜索 |

双亲表和孩子表的表头还保存结点数 $n$ 与根在顺序表中的位置 $r$。

多重链表还有两种结点格式。定长格式为每个结点设置 $k$ 个孩子指针，其中 $k$ 为树的度；有 $n$ 个结点时，$nk$ 个指针域中只有 $n-1$ 个保存分支，故空链域数为

$$
nk-(n-1)=n(k-1)+1.
$$

可变长格式按每个结点的实际度 $d$ 设置 `degree` 和 $d$ 个指针，节省空链域但结点不同构，操作不便。孩子链表在同构结点与空间利用之间取得折中。

孩子—兄弟结点结构为：

```c
typedef struct CSNode {
    TElemType data;
    struct CSNode *firstchild;
    struct CSNode *nextsibling;
} CSNode, *CSTree;
```

### 树、森林与二叉树的转换

孩子—兄弟表示与二叉链表的物理结构相同，只是字段解释不同：

| 一般树/森林关系 | 对应二叉树关系 |
| --- | --- |
| 第一个孩子 | 左孩子 |
| 下一个兄弟 | 右孩子 |
| 森林中的第一棵树 | 对应二叉树的根 |
| 第一棵树根的子树森林 | 对应二叉树的左子树 |
| 森林中剩余的树 | 对应二叉树的右子树 |

设森林 $F=\{T_1,T_2,\ldots,T_m\}$。转换成二叉树 $B=(root,LB,RB)$：

1. $m=0$ 时，$B$ 为空；
2. $m>0$ 时，$root$ 是 $T_1$ 的根；
3. $LB$ 由 $T_1$ 根的子树森林递归转换；
4. $RB$ 由 $\{T_2,T_3,\ldots,T_m\}$ 递归转换。

逆过程按同一分解恢复：二叉树根成为第一棵树的根，左子树恢复其子树森林，右子树恢复剩余森林。两种递归定义互逆，因此建立确定对应关系。

这一“确定对应”以孩子和森林中各树的先后次序已经固定为前提；交换兄弟次序会改变二叉树中的右链。

### 树与森林的遍历对应

树有两种基本遍历：

- **先根遍历**：访问根，再依次先根遍历每棵子树；
- **后根遍历**：依次后根遍历每棵子树，再访问根。

森林非空时，先序遍历依次执行“第一棵树的根 → 第一棵树根的子树森林 → 剩余森林”；中序遍历依次执行“第一棵树根的子树森林 → 第一棵树的根 → 剩余森林”。

转换为二叉树后，森林先序对应二叉树先序，森林中序对应二叉树中序。教材例中，一棵树的先根、后根序列分别为 `ABCDE`、`BDCEA`；一个森林的先序、中序序列分别为 `ABCDEFGHIJ`、`BCDAFEHJIG`。

## 6.5 树与等价问题

<!-- source: section="6.5" source_file="6-5-equivalence-problem/index.md"

### 等价关系、等价类与集合森林

集合 $S$ 上的关系 $R$ 若同时满足自反、对称和传递，就是等价关系。元素 $x$ 生成的等价类为

$$
[x]_R=\{y\mid y\in S\land xRy\}.
$$

等价关系把 $S$ 唯一划分为若干两两不相交、并集为 $S$ 的等价类。

若 $m$ 个等价偶对作用于 $n$ 个元素，划分过程为：

1. 每个元素先构成一个单元素集合；
2. 对偶对 $(x,y)$，分别找到二者所在集合；
3. 若根不同，就合并两个集合；处理完全部偶对后，剩余集合即为等价类。

对应抽象操作是 `Initial`（建立单元素集合）、`Find`（找所属集合）和 `Merge`（合并两个不相交集合）。实现时用一片森林表示集合划分：每棵树是一类，每个结点是类中成员，根兼作该类名称。

教材的 `MFSet` 还约定 $n>0$，成员是区间 $[-maxnumber,maxnumber]$ 内的整数；各子集两两不相交，其并集为全集 $S$。

### 基本 Find 与 Merge

双亲表按 $1,2,\ldots,n$ 编号。非根结点的 `parent` 保存双亲下标，根的 `parent` 为非正值。算法 6.8 从元素沿双亲链走到根；算法 6.9 把一个根指向另一个根：

```cpp
int Find(MFSet S, int i) {
    if (i < 1 || i > S.n) return -1;
    while (S.nodes[i].parent > 0)
        i = S.nodes[i].parent;
    return i;
}

Status MergeRoots(MFSet &S, int i, int j) {
    if (i < 1 || i > S.n || j < 1 || j > S.n) return ERROR;
    S.nodes[i].parent = j;  /* i、j 必须是不同集合的根 */
    return OK;
}
/* 算法 6.8、6.9 的核心 */
```

若树深为 $d$，`Find` 为 $O(d)$，已知两个根后的链接为 $O(1)$。若每次都让大集合的根指向小集合的根，$n-1$ 次合并可形成深度 $n$ 的单链；若每次合并后又查找同一深层元素，总时间可达 $O(n^2)$。

### 按大小合并

算法 6.10 令根的 `parent` 保存集合大小的负值；非根仍保存正的双亲下标。比较两个根时，负值绝对值较小者代表较小集合，应把它接到较大集合的根下，并把两个负值相加作为新大小：

```text
MIX(i, j)  // i、j 是不同集合的根
require 1 ≤ i,j ≤ S.n; otherwise fail
if parent[i] > parent[j]       // |parent[i]| 更小
    parent[j] += parent[i]
    parent[i] = j
else
    parent[i] += parent[j]
    parent[j] = i
```

不变量是：根保存本集合大小的相反数，非根保存双亲下标；一次合并后这两个约定仍成立。

按大小合并所得树的深度不超过 $\lfloor\log_2 n\rfloor+1$。证明要点是：只有接到另一根下的较小树整体深度增加 1；若较小树有 $m\le n/2$ 个元素，则其原深度至多为 $\lfloor\log_2m\rfloor+1$，合并后至多为 $\lfloor\log_2n\rfloor+1$。教材在规模为 $n$、至多 $n-1$ 次合并的划分过程中给出 $O(n\log_2 n)$ 的结论。

> **🧭 教材写法与应试实现**
>
> 原书 PDF 第 152 页（书页 142）确实把算法 6.10 写成 `void mix_mfset(...)`，但越界分支和函数末尾分别执行 `return ERROR;`、`return OK;`，这是函数头与函数体的接口冲突。函数体表达的是“返回操作状态”的约定；应试实现若保留 `ERROR/OK`，函数头应一致地声明为 `Status mix_mfset(...)`。若坚持 `void`，就应把合法性检查移到调用处或只作无返回值的提前结束，不能再返回状态值。本节伪代码用 `fail` 表示失败语义，不把教材的不一致签名当作可编译接口。

### 路径压缩

算法 6.11 在一次查找中先找到根，再把查找路径上的每个结点直接改为根的孩子：

```cpp
int FindCompress(MFSet &S, int i) {
    if (i < 1 || i > S.n) return -1;
    int root = i;
    while (S.nodes[root].parent > 0)
        root = S.nodes[root].parent;

    for (int k = i, next; k != root; k = next) {
        next = S.nodes[k].parent;
        S.nodes[k].parent = root;
    }
    return root;
}
/* 算法 6.11 的核心 */
```

第二趟改链前必须先保存原双亲，否则会丢失尚未压缩的后续路径。路径压缩不改变集合划分和根，只缩短后续查找路径。

教材给出：按大小合并与路径压缩共同用于规模为 $n$ 的等价类划分时，时间复杂度为

$$
O(n\alpha(n)).
$$

若 $A(x)=A(x,x)$ 表示单变量阿克曼函数，$\alpha(n)$ 是使 $A(x)\ge n$ 的最小 $x$；对通常遇到的正整数 $n$，教材说明 $\alpha(n)\le 4$。

例 6-1 依次处理

$$
(1,2),(3,4),(5,6),(7,8),(1,3),(5,7),(1,5),\ldots
$$

每个偶对都先查根；同根时跳过，不同根时合并。若下一偶对为 $(8,9)$，对 8 执行压缩查找后，8 到原根路径上的结点都直接指向根。

## 6.6 哈夫曼树及其应用

<!-- source: section="6.6" source_file="6-6-huffman-tree-and-applications/index.md"
     pdf_pages="154-159" book_pages="144-149" items="算法6.12-6.13, 例6-2, 图6.22-图6.27" -->

### 路径长度、WPL 与哈夫曼树

路径长度是两结点间路径上的分支数；树的路径长度是根到所有结点的路径长度之和。带权结点的路径长度等于该结点权值乘以根到它的路径长度。树的带权路径长度只对叶子求和：

$$
WPL=\sum_{i=1}^{n}w_i l_i,
$$

其中 $w_i$ 是第 $i$ 个叶子的权值，$l_i$ 是根到该叶子的分支数。给定 $n$ 个叶子权值，使 WPL 最小的二叉树称为最优二叉树或哈夫曼树。

对叶子权值 $7,5,2,4$，教材三种树形的 WPL 为：

| 树形 | 计算 | WPL |
| --- | --- | ---: |
| 四个叶子深度均为 2 | $7\times2+5\times2+2\times2+4\times2$ | 36 |
| 深度依次为 3、3、1、2 | $7\times3+5\times3+2\times1+4\times2$ | 46 |
| 深度依次为 1、2、3、3 | $7\times1+5\times2+2\times3+4\times3$ | 35 |

### 哈夫曼构造

给定权值集合 $W=\{w_1,w_2,\ldots,w_n\}$：

1. 建立 $n$ 棵单结点带权树，组成森林 $F$；
2. 从 $F$ 选根权值最小的两棵树，作为新根的左右子树，新根权值为二者之和；
3. 从 $F$ 删除这两棵树并加入新树；
4. 重复至 $F$ 只剩一棵树。

每轮合并后，新根权值等于其两棵子树根权值之和；尚未被选作孩子的根才可参与下一次最小值选择。源文没有给出 `Select` 的具体实现，因此不能仅由算法 6.12 的框架确定建树的具体时间复杂度。

哈夫曼树也可优化带概率的二叉判定过程。教材五个分数段的比例为 $0.05,0.15,0.40,0.30,0.10$；原顺序判定使 80% 的数据至少经过 3 次比较。在 10 000 个输入上，原判定过程需 31 500 次比较，按相应带权树拆分比较后为 22 000 次。

### 前缀编码与译码

不等长编码只有满足“任何字符的编码都不是另一字符编码的前缀”时才能逐位唯一译码，这类编码称为前缀编码。把字符放在二叉树叶子上，约定左分支为 0、右分支为 1，根到叶子的分支串就是编码；叶子之间不存在祖先关系，因此不会互为前缀。

教材在原书 PDF 第 156 页（书页 146）依次使用了三组不同码表，不能把它们混为一组：

1. **定长、可逐两位译码**：`A=00,B=01,C=10,D=11`。电文 `ABACCDA` 编成

   ```text
   00010010101100
   ```

   共 14 位。
2. **较短但不能唯一译码的反例**：`A=0,B=00,C=1,D=01`。同一电文编成

   ```text
   000011010
   ```

   共 9 位；但 `0` 是 `00`、`01` 的前缀，所以串 `0000` 可解释为 `AAAA`、`ABA` 或 `BB`。它只说明“单纯追求短码会产生歧义”，不是可用的前缀编码。
3. **图 6.25 的前缀码**：`A=0,B=10,C=110,D=111`。这组码用于说明叶子路径形成前缀码，不属于上面的 9 位反例；若另行把它用于 `ABACCDA`，可得 `01001101101110`，仍为 14 位。

若第 $i$ 种字符出现 $w_i$ 次、码长为 $l_i$，电文总长度为

$$
\sum_{i=1}^{n}w_i l_i,
$$

它正是编码树的 WPL。因此，用字符频率作叶子权值构造哈夫曼树，可得到总长度最短的二进制前缀编码。

译码从根开始逐位读码：0 走左孩子，1 走右孩子；到叶子就输出该字符，并回到根处理下一段。输入结束时若停在非根的内部结点，说明最后一段不是完整码字。

### 存储结构与算法 6.12

严格的哈夫曼树没有度为 1 的结点。若有 $n$ 个叶子，则共有 $2n-1$ 个结点。教材用数组 `HT[1..2n-1]` 存储，下标 0 不用；`HT[1..n]` 是叶子，`HT[n+1..2n-1]` 是合并生成的内部结点：

```c
typedef struct {
    unsigned int weight;
    unsigned int parent, lchild, rchild;
} HTNode, *HuffmanTree;

typedef char **HuffmanCode;
```

算法 6.12 建树时，`Select(HT,1..i-1)` 只在 `parent==0` 的根中选最小的两个下标 `s1,s2`，再令二者的双亲为新结点 $i$。求码时从叶子沿 `parent` 逆向到根：当前结点是双亲左孩子就在码串前端写 0，否则写 1；每个码串按实际长度单独分配。

源算法在 $n\le1$ 时直接返回，因此单字符字母表的编码约定没有在该实现中给出。若权值相同，`Select` 的并列选择和左右次序也需由实现另行规定；它们会改变具体码字，但不改变算法“每轮合并两个最小权根”的要求。

### 算法 6.13：利用双亲域无栈求码

另一做法从根向下非递归遍历，把 `weight` 临时当状态：

| 状态 | 含义与动作 |
| --- | --- |
| 0 | 尚未访问；标为 1，若有左孩子则写 0 并下行；若左右孩子都空则记录叶子编码 |
| 1 | 左侧已处理；标为 2，若有右孩子则写 1 并下行 |
| 2 | 左右侧均处理；状态清 0，沿 `parent` 返回并缩短当前码串 |

该算法依靠双亲域回退，不另设栈；但它把所有 `weight` 清为遍历状态，结束后原权值不会自动恢复。若后续仍需权值，应另设状态域或事先保存。

## 6.7 回溯法与树的遍历

<!-- source: section="6.7" source_file="6-7-backtracking-and-tree-traversal/index.md"

### 状态树与回溯不变量

回溯法把求解过程看成对一棵隐含状态树的先序遍历。树不必预先建立：每个结点表示当前部分选择，每条分支表示一次候选决策；发现当前状态违反约束时立即停止扩展该分支。子调用返回后必须撤销本层选择，使状态恢复到进入本层前。

完整解叶子与被剪枝的失败叶子不同：前者满足全部约束，后者只表示当前部分状态已经不可能扩展成解。

### 幂集：算法 6.14 与 6.15

对 $A=\{1,2,3\}$，

$$
P(A)=\{\{1,2,3\},\{1,2\},\{1,3\},\{1\},
\{2,3\},\{2\},\{3\},\varnothing\}. \tag{6-6}
$$

对每个元素只有“取”或“舍”两种决策。算法 6.14 用抽象的 `Take/Reject` 表示状态变化；进入 `PowerSet(i,n)` 时，前 $i-1$ 个元素已经决定，$i>n$ 时输出一个子集。算法 6.15 用线性表 `B` 显式保存当前子集：

```cpp
void GetPowerSet(int i, List A, List &B) {
    if (i > ListLength(A)) {
        Output(B);
        return;
    }
    ElemType x;
    GetElem(A, i, x);
    int k = ListLength(B);

    ListInsert(B, k + 1, x);       /* 取 */
    GetPowerSet(i + 1, A, B);
    ListDelete(B, k + 1, x);       /* 恢复到进入本层前 */
    GetPowerSet(i + 1, A, B);      /* 舍 */
}
/* 算法 6.15 的核心；初始 B 为空，i=1 */
```

每个元素对应一层二选一决策，叶子与幂集元素一一对应；$n=3$ 时有 $2^3=8$ 个叶子。恢复现场必须发生在“取”分支返回之后、“舍”分支开始之前。

### $n$ 皇后：约束剪枝

在 $n\times n$ 棋盘放置 $n$ 个皇后，任意两个皇后不能同一行、同一列或同一对角线。进入 `Trial(i,n)` 时，前 $i-1$ 行已各放一个互不攻击的皇后；第 $i$ 行依次尝试各列：

```c
void Trial(int i, int n) {
    if (i > n) {
        OutputBoard();
        return;
    }
    for (int j = 1; j <= n; ++j) {
        PlaceQueen(i, j);
        if (CurrentBoardIsLegal())
            Trial(i + 1, n);
        RemoveQueen(i, j);
    }
}
/* 算法 6.16；n=4 时初始调用 Trial(1,4) */
```

合法性检查决定是否剪枝，而 `RemoveQueen` 无论本次尝试成功、失败或递归返回都要执行，才能保持“进入下一候选前棋盘仍只含前 $i-1$ 行合法布局”的不变量。

### 相似、等价与形态递推

两棵二叉树相似，是指二者都为空，或二者都非空且左、右子树分别相似。两棵树等价，还要求所有对应结点的数据元素相同。本节只按形态计数，即计数彼此不相似的二叉树。

设 $b_n$ 为含 $n$ 个结点的不同二叉树形态数。空树也作为一种形态：

$$
b_0=1,\qquad b_1=1,\qquad b_2=2,\qquad b_3=5.
$$

含 $n$ 个结点的非空二叉树除根外，若左子树有 $i$ 个结点，右子树就有 $n-i-1$ 个结点；左右位置不可交换，故

$$
b_n=\sum_{i=0}^{n-1}b_i\,b_{n-i-1},\qquad n\ge1. \tag{6-7}
$$

### 生成函数与 Catalan 数

定义生成函数

$$
B(z)=\sum_{k=0}^{\infty}b_kz^k. \tag{6-8}
$$

由级数乘法及式 (6-7)，

$$
B^2(z)=\sum_{p=0}^{\infty}
\left(\sum_{i=0}^{p}b_i b_{p-i}\right)z^p
=\sum_{p=0}^{\infty}b_{p+1}z^p,
$$

所以

$$
zB^2(z)=B(z)-1. \tag{6-9}
$$

解 $zB^2-B+1=0$ 得

$$
B(z)=\frac{1\pm\sqrt{1-4z}}{2z}.
$$

由 $b_0=1$，必须满足 $\lim_{z\to0}B(z)=1$，因此取负号分支：

$$
B(z)=\frac{1-\sqrt{1-4z}}{2z}. \tag{6-10}
$$

使用二项式展开

$$
(1-4z)^{1/2}
=1+\sum_{m=1}^{\infty}\binom{1/2}{m}(-4z)^m,
$$

得到

$$
B(z)=\sum_{m=0}^{\infty}\frac{1}{m+1}\binom{2m}{m}z^m
=1+z+2z^2+5z^3+14z^4+42z^5+\cdots. \tag{6-11}
$$

比较 $z^n$ 系数：

$$
b_n=\frac{1}{n+1}\binom{2n}{n}
=\frac{1}{n+1}\frac{(2n)!}{n!\,n!}. \tag{6-12}
$$

这就是 Catalan 数。

### 前序与中序序列重建

在结点能够被唯一识别、因而根在中序序列中的位置能够唯一确定时，前序序列与中序序列共同唯一确定一棵二叉树：

1. 前序第一个结点是根；
2. 根在中序中的位置划分左右子树结点；
3. 左子树结点数把前序剩余部分切成左右子树前序；
4. 对左右两部分递归。

例 6-5 的前序为 `ABCDEFG`，中序为 `CBEDAFG`。根 A 把中序分成 `CBED` 与 `FG`，对应前序为 `BCDE` 与 `FG`；继续递归可写成

```text
A(
  left = B(left=C, right=D(left=E, right=∅)),
  right = F(left=∅, right=G)
)
```

固定同一前序序列时，不同树形对应不同中序序列，可能数仍为 $b_n$。

### 合法出栈序列与计数

中序非递归遍历可看成结点入栈、出栈并在出栈时访问。固定前序入栈次序 $1,2,\ldots,n$ 后，所有可能的中序序列恰好对应这 $n$ 个元素的合法出栈序列，其数量为

$$
\binom{2n}{n}-\binom{2n}{n-1}
=\frac{1}{n+1}\binom{2n}{n}. \tag{6-13}
$$

它与式 (6-12) 相同，从栈过程再次得到二叉树形态数。

### 有序树的计数

孩子—兄弟转换把一棵含 $n$ 个结点的有序树变成一棵含 $n$ 个结点的二叉树；原树根没有兄弟，所以对应二叉树根的右子树为空，而其左子树可以是任意含 $n-1$ 个结点的二叉树。因此有序树形态数

$$
t_n=b_{n-1}.
$$

这里计数的是有序树。无序树中，同一结点的孩子交换次序不会产生新形态，不能直接套用这一结论。

## 章末条件对照

| 结论 | 不可省略的条件 |
| --- | --- |
| 第 $i$ 层至多 $2^{i-1}$ 个结点 | 二叉树，根为第 1 层 |
| $n_0=n_2+1$ | 非空二叉树；$n_0,n_2$ 分别按结点度 0、2 计数 |
| 完全二叉树编号公式 | 层序、从左到右、编号从 1 开始 |
| 顺序存储的亲子下标 | 逻辑编号从 1 开始；教材数组下标为编号减 1 |
| 遍历辅助空间 $O(h)$ | 二叉链表的递归或显式栈实现；$h$ 为树高 |
| 线索指针可用 | 对应孩子指针原本为空，且前驱/后继所属遍历次序已确定 |
| 路径压缩不改集合 | 只把查找路径上的非根结点改为直接指向同一根 |
| 哈夫曼 WPL | 只对带权叶子的 $w_i l_i$ 求和 |
| 前序 + 中序唯一重建 | 根在中序中的位置可唯一确定 |
| $t_n=b_{n-1}$ | 一般树是有序树，并使用孩子—兄弟对应 |
