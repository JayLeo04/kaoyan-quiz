# 第 2 章 线性表

> **📌 本章主线**
>
> 线性表描述“同类元素排成有限序列”的逻辑结构；顺序表用地址连续表示次序，链表用指针或游标表示次序。复习时始终分清逻辑位序、物理位置、定位成本与已知位置后的修改成本，再把同一套基本操作用于集合归并和多项式运算。

> **🎯 408 复习定位**
>
> 需要会判断插入、删除的合法位序与移动/改链方向；会写顺序表、单链表和双向链表的关键分支；会说明头指针、头结点、首元结点、尾指针与空表状态；会在算法所依赖的基本操作成本下分析复杂度。

> **🧭 代码阅读约定**
>
> 教材代码采用 C 风格算法描述，但含引用参数 `&`、省略类型的临时变量和简写输入语句，不能直接当作现代 C 源程序编译。下文保留接口语义、边界判断和关键更新，代码围栏据其引用参数标为 `cpp`。

## 本章知识地图

- **逻辑结构**：有限序列、唯一首尾、除端点外唯一直接前驱和直接后继。
- **顺序表示**：位序可由基地址直接换算为地址；插删通常需要移动元素。
- **链式表示**：结点地址可离散；访问第 $i$ 个元素要沿链定位，已知前驱或当前结点后可常数次改链。
- **结构变体**：静态链表以数组游标代替指针，循环链表改变终止条件，双向链表补充前驱指针。
- **典型应用**：集合并与有序归并、一元多项式的稀疏表示和破坏性相加。

## 2.1 线性表与抽象数据类型

### 线性表的定义与边界

**线性表**是 $n$ 个具有相同特性的数据元素构成的有限序列：

$$
(a_1,\ldots,a_{i-1},a_i,a_{i+1},\ldots,a_n) \tag{2-1}
$$

同一表中的元素属于同一数据对象；相邻元素之间存在有次序的序偶关系。$a_{i-1}$ 是 $a_i$ 的直接前驱，$a_{i+1}$ 是 $a_i$ 的直接后继。

线性结构在非空有限集中满足：

| 元素位置 | 直接前驱 | 直接后继 |
| --- | --- | --- |
| 第一个元素 $a_1$ | 无 | $n>1$ 时唯一；$n=1$ 时无 |
| 中间元素 $a_i\ (1<i<n)$ | 唯一 | 唯一 |
| 最后一个元素 $a_n$ | $n>1$ 时唯一；$n=1$ 时无 | 无 |

元素个数 $n\ge 0$ 称为表长；$n=0$ 时是空表。非空表中 $a_i$ 的逻辑位置为第 $i$ 位，$i$ 称为它的**位序**，教材位序从 1 开始。

一个数据元素可由多个**数据项**组成，此时常称为**记录**；含大量记录的线性表又称**文件**。例如，一条学生健康记录可由姓名、学号、性别、年龄、班级和健康状况 6 个数据项组成。这些称谓不改变线性表“同类元素有序排列”的逻辑关系。

### ADT List 的操作契约

设 `L` 已存在时，其基本操作按下表理解。带 `&` 的参数由操作修改。

| 操作 | 前置条件 | 结果或失败语义 |
| --- | --- | --- |
| `InitList(&L)` | 无 | 构造空表 |
| `DestroyList(&L)` | `L` 已存在 | 销毁 `L`，使其不再存在 |
| `ClearList(&L)` | `L` 已存在 | 保留表对象，将其重置为空表 |
| `ListEmpty(L)` | `L` 已存在 | 空表返回 `TRUE`，否则返回 `FALSE` |
| `ListLength(L)` | `L` 已存在 | 返回元素个数 |
| `GetElem(L,i,&e)` | $1\le i\le \operatorname{ListLength}(L)$ | 以 `e` 返回第 $i$ 个元素 |
| `LocateElem(L,e,compare)` | `compare` 是判定函数 | 返回第一个满足关系的元素位序；不存在时返回 0 |
| `PriorElem(L,cur_e,&pre_e)` | `cur_e` 在表中且不是首元 | 返回直接前驱；否则失败，`pre_e` 无定义 |
| `NextElem(L,cur_e,&next_e)` | `cur_e` 在表中且不是尾元 | 返回直接后继；否则失败，`next_e` 无定义 |
| `ListInsert(&L,i,e)` | $1\le i\le \operatorname{ListLength}(L)+1$ | 在原第 $i$ 个元素之前插入；表长加 1 |
| `ListDelete(&L,i,&e)` | 表非空且 $1\le i\le \operatorname{ListLength}(L)$ | 删除第 $i$ 个元素并以 `e` 返回其值；表长减 1 |
| `ListTraverse(L,visit)` | `L` 已存在 | 按次序访问各元素；任一次 `visit` 失败则整体失败 |

> **⚠ 易错提醒**
>
> “在第 $i$ 个位置插入”指插到原第 $i$ 个元素之前，因此空表的唯一合法插入位序是 1，非空表尾插的位序是 $n+1$；删除的最大合法位序仍是 $n$。

### 例 2-1：集合并集

用线性表 `LA`、`LB` 表示集合 $A$、$B$。算法 2.1 逐个取出 `LB` 的元素：若 `LA` 中找不到相等元素，就追加到 `LA` 表尾，最终使 `LA` 表示 $A\cup B$。

```text
for i = 1 .. length(LB):
    e = GetElem(LB, i)
    if LocateElem(LA, e, equal) == 0:
        append e to LA
```

处理完 `LB` 的前 $k$ 个元素后，不变量是：`LA` 恰好表示原集合 $A$ 与这 $k$ 个元素的并集。集合语义要求同一集合内不保留重复成员。

若 `GetElem` 和表尾 `ListInsert` 为 $O(1)$，而 `LocateElem` 与当前表长成正比，则以执行过程中 `LA` 的最大长度 $M$、`LB` 的长度 $n$ 计，算法 2.1 为 $O(Mn)$；教材写作 $O(\operatorname{ListLength}(LA)\times\operatorname{ListLength}(LB))$。

### 例 2-2：两个有序表归并

前置条件是 `LA`、`LB` 都按值**非递减**排列。算法 2.2 用位序 `i`、`j` 指向两表当前元素，把较小者追加到新表 `LC`；相等时先取 `LA` 的元素，之后另一份仍会被取出，因此重复值被保留。

```text
i = j = 1
while i <= length(LA) and j <= length(LB):
    if LA[i] <= LB[j]: append LA[i] to LC; i++
    else:              append LB[j] to LC; j++
append the unconsumed suffix of the nonempty list
```

循环不变量是：`LC` 始终非递减，且恰好由 `LA[1..i-1]` 与 `LB[1..j-1]` 的全部元素组成。任一表耗尽后，只可能执行两个“追加剩余段”循环中的一个。

若 `GetElem` 与表尾插入均为 $O(1)$，每个输入元素只进入 `LC` 一次，算法 2.2 的时间为 $O(m+n)$，其中 $m,n$ 为两表长度。这个结论依赖基本操作成本；不能脱离具体存储表示直接套用。

## 2.2 顺序表

### 顺序存储与随机存取

顺序存储用一组地址连续的存储单元依次保存线性表元素。若每个元素占 $l$ 个存储单元，$LOC(a_1)$ 为基地址，则

$$
LOC(a_{i+1})=LOC(a_i)+l,
$$

$$
LOC(a_i)=LOC(a_1)+(i-1)\times l。\tag{2-2}
$$

逻辑相邻元素的物理地址也相邻。给定基地址和位序即可直接算出地址，所以顺序表是随机存取结构；这不等于“按值查找”也是常数时间。

| 逻辑概念 | C/C++ 表示 |
| --- | --- |
| 第 $i$ 个元素，位序从 1 开始 | `elem[i - 1]` |
| 当前表长 | `length` |
| 已分配容量 | `listsize` |
| 空表 | `length == 0` |
| 表满 | `length >= listsize` |

算法 2.3 使用动态一维数组初始化顺序表：

```cpp
#define LIST_INIT_SIZE 100
#define LISTINCREMENT 10
typedef struct {
    ElemType *elem;  // 基址
    int length;      // 当前元素数
    int listsize;    // 当前容量，以 ElemType 个数计
} SqList;

Status InitList_Sq(SqList &L) {
    L.elem = (ElemType *)malloc(LIST_INIT_SIZE * sizeof(ElemType));
    if (!L.elem) exit(OVERFLOW);
    L.length = 0;
    L.listsize = LIST_INIT_SIZE;
    return OK;
}
```

### 顺序表插入：算法 2.4

在第 $i$ 个位置之前插入 `e` 的合法范围为 $1\le i\le n+1$。若表满，先把容量增加 `LISTINCREMENT`；`realloc` 可能改变基址，因此必须以返回的新基址更新 `L.elem`。

```cpp
Status ListInsert_Sq(SqList &L, int i, ElemType e) {
    if (i < 1 || i > L.length + 1) return ERROR;
    if (L.length >= L.listsize) {
        ElemType *newbase = (ElemType *)realloc(
            L.elem, (L.listsize + LISTINCREMENT) * sizeof(ElemType));
        if (!newbase) exit(OVERFLOW);
        L.elem = newbase;
        L.listsize += LISTINCREMENT;
    }
    for (int k = L.length - 1; k >= i - 1; --k)
        L.elem[k + 1] = L.elem[k];   // 从表尾向插入位移动，避免覆盖源元素
    L.elem[i - 1] = e;
    ++L.length;
    return OK;
}
```

插入前缀不变，原 $a_i,\ldots,a_n$ 整体右移一位。由后向前移动是不变量得以维持的关键：每次赋值时，被复制的源元素尚未被覆盖。

在第 $i$ 位插入需移动 $n-i+1$ 个元素；表尾插入移动 0 个，表头插入移动 $n$ 个。若在第 $i$ 位插入的概率为 $p_i$，则期望移动次数为

$$
E_{is}=\sum_{i=1}^{n+1}p_i(n-i+1)。\tag{2-3}
$$

各位置等概率时 $p_i=1/(n+1)$，故

$$
E_{is}=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac n2。\tag{2-5}
$$

### 顺序表删除：算法 2.5

删除第 $i$ 个元素的合法范围为 $1\le i\le n$。先保存被删值，再把其后元素由前向后逐一左移，最后令表长减 1。

```cpp
Status ListDelete_Sq(SqList &L, int i, ElemType &e) {
    if (i < 1 || i > L.length) return ERROR;
    ElemType *p = &L.elem[i - 1];
    e = *p;
    ElemType *q = L.elem + L.length - 1;
    for (++p; p <= q; ++p) *(p - 1) = *p;
    --L.length;
    return OK;
}
```

删除第 $i$ 位需移动 $n-i$ 个元素；删尾移动 0 个，删首移动 $n-1$ 个。若删除第 $i$ 位的概率为 $q_i$，则

$$
E_{dl}=\sum_{i=1}^{n}q_i(n-i)。\tag{2-4}
$$

各位置等概率时 $q_i=1/n$，故

$$
E_{dl}=\frac{1}{n}\sum_{i=1}^{n}(n-i)=\frac{n-1}{2}。\tag{2-6}
$$

因此顺序表插入、删除的平均移动量约为半个表，最坏和平均时间均为 $O(n)$；已知位序只能省去定位，不能省去为保持连续存储而进行的移动。

### 顺序表查找与归并

算法 2.6 从首元开始逐个调用 `compare`，返回第一个匹配元素的位序；不存在时返回 0。若首个匹配元素是 $a_i$，比较 $i$ 次；查找失败比较 $n$ 次，时间为 $O(n)$。

算法 2.7 对两个非递减顺序表使用双指针归并，并一次性为 `LC` 分配 $m+n$ 个元素的空间：

```text
pa = first(La); pb = first(Lb); pc = first(Lc)
while pa and pb both point to valid elements:
    copy the smaller current element to *pc, then advance its source and pc
copy the remaining suffix of La or Lb
```

每次比较至少使一个输入指针前进，故时间为 $O(m+n)$；新表的数据区容量和长度均为 $m+n$。

> **🧭 条件与边界**
>
> 教材算法 2.7 先计算 `elem + length - 1`。当输入表为空时，这种指针写法不宜直接移植；实现时应先分支处理长度 0，再计算尾指针。归并思想本身允许任一输入为空，结果就是复制另一表。

若两输入表分别表示内部无重复且严格递增的集合，可把相等分支改为只复制一份，从而在线性时间内得到并集。线性时间来自两个条件：不再为每个元素从表头重复查找；新表中的“插入”实际由顺序复制完成。若把元素插回原顺序表，为维持有序仍可能移动元素。

> **📚 教材扩展**
>
> 教材指出，可先用第 10 章的快速排序得到有序表，其时间复杂度为 $O(n\log n)$；这是“先排序再做集合运算”的预处理代价，不能并入一次线性归并后忽略。

## 2.3 链式表示

### 链式存储的基本边界

链式存储允许结点位于任意存储单元。每个单链结点包含数据域和指向直接后继的指针域，后继信息把物理上可能离散的结点还原为线性次序：

```text
头指针 L → [头结点 | next] → [a1 | next] → ... → [an | NULL]
```

单链表由头指针唯一确定，必须从头部沿 `next` 访问，因此是非随机存取结构。

| 名称 | 含义 | 带头结点空表时的状态 |
| --- | --- | --- |
| 头指针 | 保存链表起始结点地址的指针变量 | 仍指向头结点 |
| 头结点 | 附设在首元结点之前，可不存元素或保存附加信息 | `head->next == NULL` |
| 首元结点 | 保存第一个数据元素 $a_1$ 的结点 | 不存在 |
| 尾结点 | 保存最后一个元素，其后继为空 | 不存在 |

若不设头结点，头指针直接指向首元结点，空表才表示为 `L == NULL`。两种约定不能混用。

### 2.3.1 单链表

```cpp
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

#### 按位访问：算法 2.8

带头结点时从 `L->next` 和逻辑位序 1 同步开始。只要当前结点存在且计数尚未到 $i$，就令指针后移；若指针为空或 $i<1$，操作失败。

```cpp
Status GetElem_L(LinkList L, int i, ElemType &e) {
    LinkList p = L->next;
    int j = 1;
    while (p && j < i) { p = p->next; ++j; }
    if (!p || j > i) return ERROR;
    e = p->data;
    return OK;
}
```

访问合法第 $i$ 位需后移 $i-1$ 次；位置越过表尾时最多遍历 $n$ 个结点，所以按位访问为 $O(n)$。

#### 单链插入与删除：算法 2.9、算法 2.10

在第 $i$ 位前插入，必须先找到第 $i-1$ 个结点 `p`；带头结点使 $i=1$ 时的前驱统一为头结点。

```cpp
// s 是新结点，p 是插入位置的前驱
s->data = e;
s->next = p->next;  // 先保存原后继
p->next = s;
```

更新顺序不能颠倒：若先执行 `p->next = s`，原后继地址会丢失。合法插入范围仍为 $1\le i\le n+1$。

删除第 $i$ 个结点也先定位其前驱 `p`，再摘下并释放目标结点：

```cpp
LinkList q = p->next;
p->next = q->next;
e = q->data;
free(q);
```

合法删除范围为 $1\le i\le n$。算法 2.9、2.10 的总时间均为 $O(n)$，原因是定位前驱；若题目已给出前驱结点 `p`，插入或删除本身只改常数个指针，时间为 $O(1)$。

#### 动态建表与有序链表归并

单链表按需用 `malloc` 生成结点、用 `free` 回收结点，不必预先分配整张表的连续空间。算法 2.11 先建头结点，再把逆位序输入的 $n$ 个元素逐个头插，最终得到正序链表，时间为 $O(n)$。

算法 2.12 原地归并两个非递减带头结点单链表：

1. `pa`、`pb` 分别指向两表首元结点，`pc` 指向结果表当前尾结点。
2. 比较当前元素，把较小结点直接链接到 `pc` 之后并推进相应指针；相等时先取 `pa`，因此两份都保留。
3. 一表耗尽后，把另一表剩余链整体接到 `pc` 之后。
4. 复用 `La` 的头结点作为 `Lc`，释放 `Lb` 的头结点；输入结点之间的链接被重组。

循环不变量是：`Lc` 已接部分非递减，且只包含两表已消费的结点；`pa`、`pb` 分别指向各自尚未消费的最小元素。时间为 $O(m+n)$，且不另建数据结点。

#### 静态链表与游标

静态链表用数组分量保存结点，以整型游标 `cur` 代替地址指针：

```cpp
#define MAXSIZE 1000
typedef struct {
    ElemType data;
    int cur;
} component, SLinkList[MAXSIZE];
```

`S[0]` 充当头结点，`S[0].cur` 给出首元结点的数组下标，游标 0 表示空指针；`i = S[i].cur` 等价于沿链后移一次。结构仍需预分配数组，但插删只改游标，不移动表中元素。

算法 2.13 沿游标查找首个值为 `e` 的结点：

```cpp
int LocateElem_SL(SLinkList S, ElemType e) {
    int i = S[0].cur;
    while (i && S[i].data != e) i = S[i].cur;
    return i;  // 结点数组下标；失败为 0
}
```

源注释把返回值称为“位序”，但代码返回的是结点的数组下标/游标；静态链表中物理下标与逻辑位序不应混同。

静态链表还要自行维护**备用链表**，对应算法 2.14、算法 2.15 和算法 2.16：

| 算法 | 核心操作 | 结果 |
| --- | --- | --- |
| 2.14 `InitSpace_SL` | 令 `space[i].cur=i+1`，末分量游标置 0 | 全部空闲分量串成备用链表，`space[0].cur` 为其头游标 |
| 2.15 `Malloc_SL` | 摘下备用链表首结点 | 有空闲时返回其下标，否则返回 0 |
| 2.16 `Free_SL` | 把下标 `k` 的结点头插回备用链表 | 被删分量可再次分配 |

### 例 2-3：静态链表求对称差

算法 2.17 先用静态链表保存集合 $A$，再逐个处理集合 $B$ 的元素：当前表中存在则删除并回收结点，不存在则分配结点并插入，最终表示

$$
(A-B)\cup(B-A)。
$$

前置条件是备用空间足够。尾游标 `r` 标识原集合段的边界；删除 `r` 所指结点时必须令 `r` 回退到前驱。对教材示例 $A=(c,b,e,g,f,d)$、$B=(a,b,n,f)$，成员 `b,f` 被删，`a,n` 被插入，结果成员为 $\{c,e,g,d,a,n\}$；该实现的链上顺序为 $c,e,g,d,n,a$。

若 $|A|=m,|B|=n$，双重循环的外层最多执行 $n$ 次、每次查找最多检查 $m$ 个原集合结点，教材给出时间复杂度 $O(mn)$。

### 2.3.2 循环链表

单循环链表令尾结点的 `next` 指回头结点，使整条链形成环；非空时从任一结点沿 `next` 都能找到环中其余结点。带头结点的空循环表中，头结点的 `next` 指向自身。

循环链表的操作与单链表相近，但遍历终止条件不再是 `p == NULL` 或 `p->next == NULL`，而是指针是否再次等于头指针。因为环上没有 `NULL` 终点，照搬普通单链表的循环条件会造成无限循环或越界逻辑。

仅保留尾指针时，可由 `tail->next` 在 $O(1)$ 时间取得头结点。合并两个这种循环链表只需改动两个 `next` 指针，把一个环的尾接到另一环的表头并闭合新环，时间为 $O(1)$。

### 2.3.3 双向链表

单链表从当前结点取直接后继为 $O(1)$，但找直接前驱通常要从表头重走，为 $O(n)$。双向链表在每个结点中同时保存 `prior` 和 `next`：

```cpp
typedef struct DuLNode {
    ElemType data;
    struct DuLNode *prior;
    struct DuLNode *next;
} DuLNode, *DuLinkList;
```

对双向循环链表中的任一结点 `d`（或非循环表中前后邻接均存在的结点），双向一致性要求

$$
d\to next\to prior=d,
\qquad
d\to prior\to next=d。
$$

双向循环链表的空表只有头结点，头结点的 `next` 和 `prior` 都回指自身。

按位插入的合法范围为 $1\le i\le n+1$，按位删除为 $1\le i\le n$；教材算法先定位插入位置结点或待删结点，再执行下列改链。

在结点 `p` 之前插入新结点 `s` 时，算法 2.18 的四步更新为：

```cpp
s->prior = p->prior;
p->prior->next = s;
s->next = p;
p->prior = s;
```

删除当前结点 `p` 时，算法 2.19 先让其前驱与后继彼此相连，再释放 `p`：

```cpp
p->prior->next = p->next;
p->next->prior = p->prior;
free(p);
```

若已知 `p`，上述插删只需常数次改链；教材算法 2.18、2.19 还先调用 `GetElemP_DuL` 按位定位，所以总时间为 $O(n)$。分析时必须说明是否已经给出结点位置。

### 带头尾指针和长度的链表接口

教材进一步把“位序”弱化为“结点位置”，定义同时保存头结点、尾结点和元素个数的链表：

```cpp
typedef struct {
    Link head, tail;
    int len;
} LinkList;
```

接口包括结点分配/释放，初始化/销毁/清空，首结点插删，尾接/删尾，指定结点前后插入，取改当前元素，取头尾与前后位置，按位或按值定位，以及遍历。

| 成本 | 操作 |
| --- | --- |
| 与表长无关 | `MakeNode`、`FreeNode`、`InitList`、`InsFirst`、`DelFirst`、`InsAfter`、`SetCurElem`、`GetCurElem`、`ListEmpty`、`ListLength`、`GetHead`、`GetLast`、`NextPos` 等 |
| 与表长成正比 | `DestroyList`、`ClearList`、`Remove`、`InsBefore`、`PriorPos`、`LocatePos`、`LocateElem`、`ListTraverse` |
| 与接入结点数成正比 | `Append` |

算法 2.20 把第 $i$ 位插入改写为“定位第 $i-1$ 个位置 → 分配新结点 → 在该位置后的子表首部插入”。算法 2.21 把有序归并改写为反复从两输入表首部摘结点并追加到结果表，最后整体追加未耗尽的剩余段，再释放两输入头结点；二者与算法 2.9、2.12 的复杂度相同。

## 2.4 一元多项式的表示与相加

### 稠密表示与稀疏表示

一元 $n$ 次多项式

$$
P_n(x)=p_0+p_1x+\cdots+p_nx^n
$$

可用系数表 $(p_0,p_1,\ldots,p_n)$ 表示，指数由位序隐含。该表示适合系数较稠密的情形；对 $1+3x^{100}+2x^{20000}$，却要保存 20001 个系数，只有 3 个非零，空间浪费明显。

只保存非零项时，一般形式为

$$
P_n(x)=p_1x^{e_1}+p_2x^{e_2}+\cdots+p_mx^{e_m},\tag{2-7}
$$

其中 $p_i\ne 0$，且

$$
0\le e_1<e_2<\cdots<e_m=n。
$$

用二元组线性表

$$
((p_1,e_1),(p_2,e_2),\ldots,(p_m,e_m))\tag{2-8}
$$

即可唯一确定该多项式。最坏情况下所有 $n+1=m$ 个系数都非零，二元组方案因额外保存指数而约需双倍数据项；对高次稀疏多项式则能显著节省空间。

项数允许 $m=0$；此时表示零多项式，有序链表中没有数据项结点。

若只做求值等不改变系数和指数的操作，可用类似顺序表的表示；若运算会频繁改变项，应采用链式表示。无论哪种存储结构，项都必须按指数严格递增排列且只保存非零系数。

### Polynomial 的操作契约

| 操作 | 语义 |
| --- | --- |
| `CreatPolyn(&P,m)` | 输入 $m$ 项的系数、指数并建立多项式 |
| `DestroyPolyn(&P)` | 销毁已存在的多项式 |
| `PrintPolyn(P)` | 输出多项式 |
| `PolynLength(P)` | 返回非零项数 |
| `AddPolyn(&Pa,&Pb)` | 令 `Pa = Pa + Pb`，并销毁 `Pb` |
| `SubtractPolyn(&Pa,&Pb)` | 令 `Pa = Pa - Pb`，并销毁 `Pb` |
| `MultiplyPolyn(&Pa,&Pb)` | 令 `Pa = Pa × Pb`，并销毁 `Pb` |

有序链表版还需：`LocateElem` 在命中时返回相等结点；未命中时返回第一个指数更大结点的前驱；`OrderInsert` 按指数次序插入新项。

### 例 2-4：Polynomial 的有序链表实现

每个数据结点保存系数和指数：

```cpp
typedef struct {
    float coef;
    int expn;
} term, ElemType;

typedef LinkList polynomial;
```

算法 2.22 初始化带头结点有序链表，并把头结点数据设为系数 0、指数 $-1$。随后读取 $m$ 个非零项；若当前指数尚不存在，则分配结点并按序插入。由此维持“指数严格递增、每个指数至多一项”的不变量。

算法 2.23 令 `Pa = Pa + Pb`，直接复用两输入链表的结点。设 `qa`、`qb` 指向当前项，比较指数有四种结果：

| 条件 | 操作 | 结果表中的项 |
| --- | --- | --- |
| `qa.expn < qb.expn` | 保留 `qa`，推进 `qa` | 原 `Pa` 当前项 |
| `qa.expn > qb.expn` | 从 `Pb` 摘下 `qb`，接入 `Pa`，推进 `qb` | 原 `Pb` 当前项 |
| 指数相等且系数和非零 | 修改 `qa` 的系数，释放 `qb` | 合并项 |
| 指数相等且系数和为零 | 从 `Pa` 删除 `qa`，并释放 `qa`、`qb` | 该指数项消失 |

一表耗尽后，若 `Pb` 尚有项，就把其剩余链整体接到 `Pa`；最后释放 `Pb` 的头结点。因此该操作是**破坏性的**：调用后 `Pb` 不再存在。

循环不变量是：`Pa` 已处理前缀已经是两输入已处理项之和，指数严格递增且没有零系数项；`qa`、`qb` 指向各自尚未处理的最小指数项。每轮至少推进或删除一个当前结点，因此以两表项数 $m,n$ 计，时间随 $m+n$ 线性增长，且不另建结果数据结点。

教材示例为

$$
A(x)=7+3x+9x^8+5x^{17},
\qquad
B(x)=8x+22x^7-9x^8,
$$

相加时指数 1 的系数合为 11，指数 7 的项从 $B$ 移入，指数 8 的系数和为 0 而删除，得到

$$
A(x)+B(x)=7+11x+22x^7+5x^{17}。
$$

> **🔎 源文/转写疑点**
>
> 源 ADT 的数据对象以 $m$ 表示项数，但数据关系的索引上界写成 $n$；正文依据同段“$m$ 个项”改写为“相邻项指数严格递增”。算法 2.23 的 `SetCurElem(qa, sum)` 又把标量 `sum` 传给项类型接口；正文按紧邻注释保留其语义为“只更新 `qa` 的系数”，没有把该行当作可直接编译代码。

### 多项式乘法的分解

若

$$
B(x)=b_1x^{e_1}+b_2x^{e_2}+\cdots+b_nx^{e_n},
$$

则教材把乘法分解为一系列多项式加法：

$$
\begin{aligned}
M(x)&=A(x)\times B(x)\\
&=A(x)\times[b_1x^{e_1}+b_2x^{e_2}+\cdots+b_nx^{e_n}]\\
&=\sum_{i=1}^{n}b_iA(x)x^{e_i}。
\end{aligned}
$$

每个乘积项本身仍是一元多项式，再按前述有序链表加法逐步合并。

## 章末对照

| 维度 | 顺序表 | 单链表 | 带尾指针循环单链表 | 双向链表 |
| --- | --- | --- | --- | --- |
| 表示逻辑次序 | 连续地址 | `next` | `next` 构成环 | `prior` 与 `next` |
| 按位访问 | $O(1)$ | $O(n)$ | $O(n)$ | 按一个方向仍为 $O(n)$ |
| 已知修改位置后的插删 | 仍可能移动 $O(n)$ 个元素 | 已知前驱后为 $O(1)$ | 已知前驱后为 $O(1)$ | 已知当前结点后为 $O(1)$ |
| 按位插删总成本 | $O(n)$ | $O(n)$，定位前驱占主导 | $O(n)$，终止于回到头结点 | $O(n)$，按位定位占主导 |
| 找当前结点的直接前驱 | 地址换算可得相邻位序 | 通常 $O(n)$ | 通常 $O(n)$ | $O(1)$ |
| 空表判定 | `length == 0` | 带头结点时 `head->next == NULL` | 带头结点时 `head->next == head` | 双向循环头结点两指针均回指自身 |
| 主要空间特点 | 需连续容量，可能预留空闲区 | 每结点附加一个指针 | 每结点附加一个指针 | 每结点附加两个指针 |

> **⚠ 易错提醒**
>
> “链表插删快”只描述已经拿到前驱/当前结点后的改链成本。若题目给的是逻辑位序 $i$，单链表通常仍要先走到第 $i-1$ 个结点，总时间为 $O(n)$。
